# 생활지도 종합 현황(부장 분석 뷰) 스펙

작성: Claude, 2026-08-08. 요청 배경: 학생부장 등 실무자는 "어느 반에 몇 건, 내용이 뭐고, 문제 학생이 누구인지"가 한눈에 보여야 하는데(구 시트 운용 시절의 강점), 현행 지도 현황 탭은 학생별 카드 나열이라 종합·분석이 불가.

## 0. 핵심 설계 결정 3가지

1. **새 탭이 아니라 기존 "지도 현황" 탭을 2단 구성으로 개편한다** — 상단 "종합 현황" 섹션(신규) + 하단 기존 학생 카드 목록(유지). 탭이 이미 7개라 추가하지 않고, 부장이 들어오면 바로 종합이 보이고 클릭으로 기존 카드·상세 모달에 내려가는 동선.
2. **서버 신규 작업 0 · 추가 Firestore 읽기 0** — 기존 `records list` API 응답(권한 범위 내 학생별 기록·단계·이력 전체)을 클라이언트에서 집계만 한다. **요청당 읽기 계수: 변화 없음** (capacity review §4-2 규칙 준수 기재).
3. **신규 권한 없음** — list가 이미 호출자 범위로 자동 축소하므로(computeAccessTargets), 같은 화면이 담임에겐 자기 반 종합, all 스코프(부장·관리자)에겐 전교 종합으로 자연 분화된다. 별도 "분석 열람" 권한을 만들지 않는다.

## 1. 화면 구성 (상단 "종합 현황" 섹션)

데이터 원천: 현행 탭이 이미 받는 `students[]`(기록·status 포함) + `config`(items/stages 라벨). 모든 집계는 **유효 기록만**(voided 제외). 클라이언트 useMemo 집계.

### A. 학년 × 반 매트릭스 (요구 1순위: "어느 반에 몇 건")
- 행 = 학년(1~3), 열 = 반(1 ~ max(10, 기록 최대 반)). 셀 = 유효 기록 건수, 건수 비례 배경 농도(히트맵). 0건 반은 회색 0.
- 셀 클릭 → 하단 학생 목록에 해당 학년·반 필터 적용(기존 필터 state 재사용) + 스크롤 이동.

### B. 항목(내용)별 분포 (요구 2순위: "내용이 뭔지")
- itemId→label 가로 막대(건수 내림차순), category 구분 색. 항목 클릭 시 해당 항목 기록 보유 학생만 하단 필터(선택 구현 — 여력 없으면 표시만).

### C. 단계별 인원 현황
- currentStageId별 학생 수 배지 나열 (stage order 오름차순: 담임 N명 … 생활교육위원회 N명). 상위 단계는 경고색. 단계 배지는 기존 카드 배지 스타일 재사용.

### D. 상위 학생 목록 (요구 3순위: "문제 있는 애가 누구")
- 정렬: 현재 단계 order 내림차순 → 기간 내 유효 기록 수 내림차순. 상위 10명: 학번·이름·반·현재 단계 배지·기간 내 건수·최근 발생일.
- 행 클릭 → 기존 상세 이력 모달 열기(재사용, 신규 모달 금지).

### E. 기간 필터 (섹션 공통)
- `전체 / 최근 30일 / 최근 90일` — occurredAt 기준 클라이언트 필터. A·B·D의 건수에 적용.
- **단계(C)는 기간 필터와 무관** — 단계는 리셋 마커 기준 서버 판정값이므로 항상 "현재 판정"을 표시하고, 섹션에 "단계는 현재 기준, 건수는 선택 기간 기준" 캡션 1줄로 혼동 방지.

### F. 시트뷰 + 내보내기 (구 시트 워크플로 계승)
- "표로 보기" 토글: 피벗 테이블 — 행 = 학생(학번·이름·학년·반·현재 단계), 열 = 기록 존재 항목들, 값 = 유효 건수, 끝 열 = 합계·최근 발생일. 반·학년·기간 필터 연동. 정렬 = 합계 내림차순.
- **xlsx 다운로드** (기설치 `xlsx` 재사용 — 신규 의존성 0): 파일명 `생활지도_현황_YYYY-MM-DD.xlsx`, 위 피벗 + 캡션 행(생성일·기간·범위).
- 다운로드 버튼 옆 고정 문구: "개인정보가 포함된 파일입니다 — 업무 목적 외 사용·공유 금지" (Phase 11 관행. UI 문구에 개발 용어 금지 원칙 준수).

## 2. 하단 기존 카드 목록 변경점

- 없음(유지). A·B 클릭이 기존 학년/반 필터 state를 조작하는 연결만 추가.

## 3. 구현 분업·완료 기준

- **Antigravity**: DisciplineStatusTab 개편(섹션 컴포넌트·집계 useMemo·시트뷰·xlsx 내보내기). DoD: tsc·build 통과 후 커밋.
- **Claude**: 완료 후 표적 리뷰 — 위험 지점은 ① 집계에 voided 혼입 여부 ② 단계/건수 기간 기준 혼동(E 캡션) ③ 내보내기 파일의 PII 문구 누락 ④ 신규 fetch 추가 여부(추가 읽기 0 원칙 위반 감지).
- 수용 기준(사용자 실측): 부장 계정으로 지도 현황 진입 → 스크롤 없이 "반별 건수·항목 분포·단계 인원·상위 학생"이 보이고, 반 셀 클릭 → 그 반 학생 카드로 내려가며, 표로 보기 → xlsx 다운로드가 구 시트와 같은 정보량을 담는다.

## 4. 명시적 비범위

- 서버 API 변경·신규 컬렉션·기간별 추이 그래프(주별 라인 차트)는 이번 범위 아님 — 추이는 실사용 데이터가 쌓인 뒤 재검토(지금은 표본이 적어 의미 없음).
- 담임용 화면 분화 없음 — 같은 화면이 권한 범위로 자연 축소되는 것으로 충분.
