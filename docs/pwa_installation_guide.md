# 효명고 관리 시스템, 앱으로 설치해서 쓰세요

매번 인터넷 브라우저를 열고 주소를 찾아 접속할 필요 없이, 컴퓨터를 켜자마자 바탕화면 앱 형태로 바로 사용할 수 있습니다. 아래 3단계를 따라 간단하게 설치해 보세요.

---

### 1단계: 웹사이트에서 [앱으로 설치] 클릭하기

1. 크롬(Chrome) 브라우저로 **효명고 관리 시스템**에 접속합니다.
2. 로그인 화면이나 상단 메뉴에 있는 **`[앱으로 설치]`** 버튼을 클릭합니다.
   - 또는 브라우저 맨 위 **주소창 오른쪽**에 보이는 **설치 아이콘(모니터와 화살표 모양)**을 누르셔도 됩니다.
3. 팝업 창이 뜨면 **[설치]** 버튼을 선택합니다.

![스크린샷: 화면 상단의 '앱으로 설치' 버튼 및 주소창 오른쪽 설치 아이콘 위치](images/pwa_step1_install.png)

---

### 2단계: 컴퓨터 켤 때 자동으로 앱 켜기 (자동 시작 설정)

1. 설치가 완료되면 인터넷 창과 별개의 **독립된 전용 앱 창**으로 효명고 관리 시스템이 열립니다.
2. 앱 창 맨 위 오른쪽의 **점 3개(`⋮`) 메뉴**를 누르거나 주소창 아이콘을 클릭합니다.
3. 메뉴 항목 중 **`[컴퓨터 로그인 시 앱 실행]`** (또는 `[OS 로그인 시 앱 시작]`) 옵션을 **체크(켜기)**합니다.

> 💡 **참고:** 이 설정을 켜두시면 교무실 컴퓨터를 부팅할 때 효명고 관리 플랫폼이 자동으로 열려 바로 업무를 시작하실 수 있습니다.

![스크린샷: 앱 설정 메뉴에서 '컴퓨터 로그인 시 앱 실행' 옵션 체크 항목](images/pwa_step2_autostart.png)

---

### 3단계: 작업 표시줄에 고정하기 (선택 사항)

1. 컴퓨터 화면 아래쪽 **작업 표시줄**에 새로 생긴 **효명고 관리 시스템 아이콘**을 찾습니다.
2. 아이콘 위에서 **마우스 오른쪽 버튼**을 클릭합니다.
3. 메뉴에서 **`[작업 표시줄에 고정]`**을 선택하면 브라우저가 닫혀 있어도 언제든 한 번의 클릭으로 바로 실행할 수 있습니다.

![스크린샷: 작업 표시줄 아이콘 마우스 우클릭 후 '작업 표시줄에 고정' 선택](images/pwa_step3_pin.png)

### 📌 자주 묻는 질문 (FAQ)

- **Q. 크롬북에서도 로그인 시 자동 실행이 되나요?**
  - 크롬북이나 태블릿 환경에서는 해당 자동 시작 옵션 대신 바탕화면 및 앱 목록에 전용 아이콘으로 추가됩니다. 교무실 Windows / Mac 컴퓨터에서 위 2단계 설정을 활용하시면 편리합니다.
- **Q. 다시 일반 인터넷 웹사이트로 접속하고 싶어요.**
  - 기존 웹 주소 그대로 접속하셔도 동일하게 이용하실 수 있습니다.
