### Y-1. 기보 딱지가 나빠지는 수를 「점수 유지」라고 한다 (오표시 — 우선)

`:3548-3550` — `line.finalDelta < 0 ? "총점 N점 개선" : "점수 유지"`. **나빠짐(양수)이 else로 떨어져 「점수 유지」**가 되고 색도 emerald(초록)다. 사용자 실측: 총점 **21.5 → 24.5(+3점)** 인데 딱지는 「점수 유지」.

1. `finalDelta > 0`이면 **「총점 N점 나빠짐」 + 경고색**. `=== 0`일 때만 「점수 유지」.
2. **딱지 순서도 바꾼다 (§0-5)**: 순증이면 **총점 딱지가 맨 앞**, 「✅ 이 감점 해소」는 뒤로. 순감일 때만 지금 순서.
3. 같은 삼항식이 `:2459·2461·2462·2941·2942·2943`에도 있으나 **그쪽은 초록 후보 전용이라 나빠질 수 없다 — 건드리지 마라**(다만 §0-5 금지 형태이므로 주석 한 줄로 「여기는 delta ≤ 0 보장」을 남겨라).

### Y-2. 좁은 화면에서 「시간표 추가」가 사라진다 (재발 — 우선)

사용자: *"시간표 추가 사라짐. 직접조정은 흐려짐."* **원인은 CSS가 아니라 연쇄다** — 버튼이 `{manualMode && (…)}`(`:3197`) 안에 있고, 화면이 좁아지면 effect가 `setManualMode(false)`를 불러 **모드가 꺼지면서 버튼이 통째로 렌더에서 빠진다.** 과제 V-2는 `hidden lg:flex` 클래스만 걷었다.

1. 「시간표 추가」도 **「직접 조정」처럼 흐린 비활성 + 이유 안내**로 남긴다. **폭 조건과 모드 조건을 분리**해라 — 좁아서 못 쓰는 것과 모드가 꺼져서 안 보이는 것은 다르다.
2. 안내 말풍선(`:337` 부근)이 **잘린다**(*"…다시 쓸 수 있…"*) — 좁은 폭에서 줄바꿈되게. 문구도 **무엇이 막혔는지** 함께: 「직접 조정과 시간표 추가를 쓸 수 없습니다」류.
3. **검증은 grep이 아니라 좁은 폭 화면으로 한다** (§0-6). 보고에 **어떻게 확인했는지** 적어라.

### Y-3. 기보 미니 그리드에 ①②가 무슨 수업인지 없다

사용자: *"작업 기록엔 뭐가 1번이고 뭐가 2번인지 나와서 바로 이해 가능한데, 해결안 찾기에선 그게 없어."*

작업기록은 `HistoryMiniGrid` **옆에 `lessonNode`**를 함께 그린다(`:4547` 부근 — 「① 수학(김○○) ↔ ② 영어(박○○)」). 기보 카드는 `:3628`에서 **격자만** 넘긴다.

- 기보 카드에도 같은 방식으로 **과목(교사)** 를 붙인다.
- ⚠️ **함정 — 어느 판에서 읽나** (과제 W-1과 같은 종류): 기보는 **지금 판 기준 제안**이라 1수는 `currentGrids`면 되지만 **2수 이상이면 n번째 수는 앞선 수를 적용한 판에서** 읽어야 한다. `currentGrids`로 전부 읽으면 **2수째부터 틀린 이름**이 나온다. 누적 방식은 `historyDetails`(`:541`)에 이미 있다 — **그것을 본보기로.**

### Y-4. 교사 격자에 우클릭 빼두기가 없다 + 학급/교사 조작 전수 대조

학급 격자에는 우클릭이 **5곳**(`:2411·2453·2526·2587·2635` → `handleCellRightClick` → `handleParkCell`), 교사 격자에는 **0곳**.

사용자가 짚은 이유가 중요하다 — *"시간표를 추가한 상황이면 스크롤이 길어져서 드래그앤드롭으로 아래로 빼두기가 안 되더라고."* **트레이가 화면 밖으로 나가면 드래그가 물리적으로 불가능**하므로 우클릭은 편의가 아니라 **그 상황의 유일한 경로**다.

1. 교사 셀에 `onContextMenu` → `handleCellRightClick(d, p, hit.grade, hit.classNum)`. 그 함수가 학급·반을 인자로 받으므로 배선만 하면 된다(드래그가 `hit.grade`를 쓴 것과 동일).
2. **전수 대조 (이게 이 항목의 본론이다)**: **학급 격자에 있는 상호작용이 교사 격자에도 있는가**를 표로 대조해 보고해라 — 클릭·우클릭·집기·드래그 시작·드롭·hover·잠금 표시 등. **교사 격자에서 빠진 것이 이번이 세 번째다**(집기 → 드래그 → 우클릭). 개별 확인이 세 번 연속 놓쳤으므로 이번엔 한 번에 훑는다. 빠진 게 더 있으면 **고치지 말고 목록으로 보고**해라 — 넣을지는 Claude가 정한다.

### Y-5. 「미배정 수업 목록」 위치와 이름

1. **위치**: 카드가 **교사 그리드 컬럼 안에** 있다(`:3904` 컬럼 div 내부, `:3955`). 「시간표 추가」로 2열이 되면 **교사 시간표와 추가 패널 사이에 낀다.** 이 카드는 두 그리드 어디에도 속하지 않는 독립 정보다 — **컬럼 밖으로 빼서 추가 패널 개수와 무관하게 자리가 고정**되게. **트레이 근처가 자연스럽다**(둘 다 「판 밖에 있는 수업」이다).
2. **이름**: 사용자 질문 — *"저거 정확한 역할이 뭐야? 잠깐 빼둔 수업으로 뭔가가 미배정 되어도 목록에 아무것도 안 뜨던데."* **동작은 의도대로다**(미배정 = 솔버가 못 넣은 것 / 트레이 = 사람이 뺀 것, 별개 통). 문제는 **화면이 그 차이를 한 마디도 안 하는 것**이다.
   - 카드에 한 줄: 「편성할 때 자리를 못 찾은 수업입니다(빼둔 수업은 트레이에).」류.
   - 0건일 때 「모든 수업이 배정되었습니다」도 **무엇이 0인지** 드러나게.

**완료 확인**: tsc · build · check:ui · `check_ui_removals`(기준 커밋) · selftest 4종(`lookahead` 27 · `movecand` · `m2ops` · `unplaced`) 유지 + ⓐY-1 딱지가 순증일 때 경고형·맨 앞인지 ⓑY-2를 **좁은 폭 화면에서** 확인한 방법 ⓒY-3이 2수째를 어느 판에서 읽는지 ⓓY-4 전수 대조표 ⓔY-5 카드 위치가 추가 패널 0·1·2개에서 동일한지 — 각각 코드 근거(file:line). **핸드오버 ④ 기재**(덧붙이기만).
