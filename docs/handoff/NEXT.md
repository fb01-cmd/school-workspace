## 과제 H — 글씨 크기 1단계: 9px·10px 기계 상향

- 기준 커밋: `2fbcdda`
- **시작 전에 `docs/font_size_spec.md`를 전체 읽어라** (짧다). 이 과제는 그 스펙 §5의 「1단계」다. 아래 지시와 스펙이 어긋나면 스펙이 이긴다.

### 할 일

1. `src/` 전체에서 `text-[9px]`·`text-[10px]`을 찾는다 (현재 9px 40곳 / 10px 414곳, 파일 약 70개).
2. **건드리지 않는 것 둘** (스펙 §3):
   - **이미지·인쇄 생성 전용 렌더** — `OffscreenShareCard.tsx`(화면 밖 캡처 전용), `@media print` 블록. 통째로 제외.
   - **고밀도 격자 셀 내부** — 주간 시간표 격자·미니 프리뷰처럼 한 화면에 수십 셀이 놓인 곳의 셀 안 텍스트. 10px은 그대로 둬도 되지만 **9px은 격자 셀이라도 `text-[10px]`로 올린다.** 10px을 남긴 파일은 전부 스펙 §7 허용 목록에 추가해라 (스펙 파일의 그 목록만 고친다 — 다른 절 수정 금지).
3. 나머지 전부를 스펙 §2 등급으로 상향한다:
   - 기본값 = `text-xs` (12px).
   - 명백한 3급(단위 표기·축약 뱃지·캡션 같은 장식)만 `text-[11px]` 허용.
   - 그 자리가 1급(이름·날짜·마감·교시·상태·버튼 라벨·에러 문장)이었으면 `text-sm` (14px).
   - 애매하면 한 급 위로. 임의값(`text-[13px]` 류) 신설 금지 — 표준 클래스만.
4. **크기만 바꾼다.** 레이아웃·문구·구조·색 변경 금지. 크기 상향으로 줄바꿈·배치가 흐트러지는 곳은 고치지 말고 `파일:줄` 한 줄로 보고만 해라 (배치 수정은 2단계 과제다).
5. 커밋은 디렉터리 묶음별로 3~6개로 끊는다 (예: timetable / lifecycle / 그 외 admin / common+기타). 격자 예외로 10px을 남긴 파일은 커밋 메시지에 목록으로 적는다.

### 완료 확인 방법 (이 순서로 스스로 확인하고 결과를 보고에 적어라)

1. `grep -rn "text-\[9px\]" src/` → **0건**
2. `grep -rln "text-\[10px\]" src/` → 남은 파일 전부가 `OffscreenShareCard.tsx` 또는 스펙 §7 허용 목록과 **정확히 일치**
3. `npx tsc --noEmit` 통과 · `npm run build` 통과
4. `bash scripts/check_ui_removals.sh 2fbcdda` — 뜬 항목마다 "이 삭제가 지시에 있었나" 답을 적어라 (크기 상향 과제에서 핸들러·라벨 삭제가 나오면 그 자체가 반려 사유다)
5. 핸드오버(project_notes.md 하단): 요약 + 커밋 해시 + 배치 흐트러짐 보고 목록 + **"화면·모바일 미검증"을 명시**해라 — 360px·실기기 확인은 네 몫이 아니다(스펙 §4). 그걸 했다고 쓰면 반려다.
