## 과제 R — 구 맞교환 모드를 직접 조정으로 통합 (사용자 확정 2026-08-22 16:30)

**기준 커밋: HEAD.** 발단: 직접 조정 토글이 꺼진 상태에서 구식 수동 편집(셀 클릭 → "⇄ 맞교환" 표시 → 목적지 선택)이 병존 — 직접 조정(M1+M2)이 완전 상위 호환이므로 편집 상호작용을 하나로 합친다.

1. **구 맞교환 편집 경로 제거** (`DraftAutoTab.tsx`): 토글 꺼짐 상태의 셀 클릭 편집(집기→"이동할 목적지 셀을 선택하세요" 칩→맞교환 라벨 렌더→구 적용 흐름)을 걷어낸다. 셀 안 "⇄ 맞교환" 글자 렌더도 함께 제거(셀 불변 조항 정합).
2. **직접 조정이 유일한 편집 상호작용**: 토글은 「직접 조정(편집)」 on/off로 유지하되, 꺼짐 = **열람 전용**(셀 클릭은 교사 주간표 표시 등 열람 동작만). 1024px 미만은 기존 규칙 유지(토글 미표시 = 열람만).
3. **보존 확인 (지우기 전에 grep으로 확인하고 보고)**: ⓐ 미배정 수업을 그리드에 배치하는 경로가 구 편집 흐름에 걸려 있으면 직접 조정 쪽으로 이관(미배정 카드 클릭 = held 집기와 동일 처리 권장 — evaluateHeldCandidates 재사용) ⓑ 해결안 찾기·물어보기의 미리보기/적용 경로는 구 모드와 무관해야 함(확인만) ⓒ 자리표시·동시수업 방어 로직은 직접 조정 경로에 이미 있으므로 중복 제거 가능.
4. 관련 안내 문구 갱신(토글 꺼짐 상태의 힌트 등 — 개발 용어 금지).

5. **네이밍 3건 교체 (사용자 확정 2026-08-22)** — 화면 라벨만 바꾼다(데이터 필드·주소·스크립트·저장값 불변):
   - 「자동 작성」 → **「시간표 편성」** (탭·버튼·안내문의 해당 라벨. 실행 버튼류는 「자동으로 초안 만들기」처럼 자동이 한 동작임이 드러나게)

   - 「선생님별 주당 수업 시간」 → **「수업 시수」** (탭·머리 라벨)
   - grep으로 각 라벨의 노출 지점 전수(사이드바·탭·툴팁·빈 상태 안내)를 찾아 바꾸고, 바꾼 지점 목록을 보고에 적어라. 화면 머리 규칙(맨 위 줄 이름 = 누른 이름) 유지 — `npm run check:ui`가 잡아준다.
