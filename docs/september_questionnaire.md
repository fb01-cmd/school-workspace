# 시간표 자동 작성 준비 — 여쭤볼 것들

안녕하세요. 학교 시스템으로 시간표를 짜는 준비를 하고 있습니다. **이번 2학기
시간표를 짜실 때 실제로 지키셨던 조건들**이 지금은 담당 선생님의 머릿속과 컴시간
설정에만 있어서, 그걸 시스템에 등록해 두려고 몇 가지 여쭙습니다. 한번 등록해 두면
새 학기에는 바뀐 부분만 고치면 됩니다.

- 응답에 **10분** 정도 걸립니다.
- 1~3번은 **이번 2학기 시간표 기준**으로, 4~5번은 학기와 무관한 평소 기준을 여쭙는 것입니다.
- 정확하지 않아도 됩니다 — 기억나는 대로 적어 주셔도 충분합니다.

- [ ] 가능하면 좋지만 필수는 아니다
