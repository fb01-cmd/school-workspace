# 시간표 자동 작성 준비 — 여쭤볼 것들

안녕하세요. 내년 1학기 시간표를 학교 시스템으로 짜기 위한 준비로, 시간표를 짤 때
실제로 지키시는 규칙들을 여쭙습니다. 지금까지는 담당 선생님의 머릿속과 컴시간
설정에만 있던 기준들을 시스템에 등록해 두려는 목적입니다.

- 응답에 **10~15분** 정도 걸립니다.
- 정확한 표가 아니어도 됩니다 — 기억나는 대로, 관행 수준으로 적어 주셔도 충분합니다.
- 학기마다 달라지는 내용(올해 누가 몇 반을 맡는지 등)이 아니라, **매 학기 공통으로
  지키는 규칙**을 여쭙는 것입니다.

## 4. 좋은 시간표의 기준

시간표를 짤 때 아래 두 가지를 실무에서 얼마나 중요하게 보시는지 여쭙습니다.

**4-1. 선생님 하루 수업의 오전/오후 쏠림**
한 선생님의 하루 수업이 오전에만 또는 오후에만 몰리는 것을 피하려고 신경 쓰시나요?

- [ ] 중요하게 지킨다 (가급적 오전·오후에 나눠 배치)
- [ ] 웬만하면 피하지만 어쩔 수 없으면 둔다
- [ ] 특별히 신경 쓰지 않는다

**4-2. 같은 과목의 반별 교시 돌리기 (순배)**
같은 과목이 여러 반에 들어갈 때, 특정 반만 늘 늦은 교시(6·7교시)에 걸리지 않도록
반마다 교시를 돌아가며 배치하는 것을 실무에서 실제로 신경 쓰시나요?

- [ ] 중요하게 지킨다
- [ ] 가능하면 좋지만 필수는 아니다
- [ ] 특별히 신경 쓰지 않는다

**4-3.** 그 밖에 "이건 꼭 지켜야 좋은 시간표"라고 생각하시는 기준이 있으면
자유롭게 적어 주세요. (예: 담임은 자기 반 1교시 주 O회 이상, 특정 과목은 오전 배치 등)

## [제2부] 내부 메모 — 회수 후 반영 매핑 (전달 금지)

| 문항 | 반영처 | 방법 |
|---|---|---|
| 1·1-1·1-2 | 교사 교시 금지 등록부 (`teacherSlotBans`) | 시간표 작성 메뉴 등록부 UI로 입력. 1-1 구분 = kind `assign`(배정금지, 기본) / `move`(이동금지). 시간강사 출근 요일 = 비출근 요일 전일 배정금지. E-2 "말로 입력하기"로 문장 그대로 넣어도 됨(사람 확인 관문 검증 겸용) |
| 2 | 연속수업 등록부 (`consecutiveRules`) | 연속 형태를 콤마 표기로 변환 ("2시간 연속 2회" → `"2,2"`). **소유 우선순위 주의**: 해당 수업이 동시수업·특별실 등록부에 이미 있으면 연속 속성은 그쪽 등록부에 등재(이중 등재 금지, phase9c_spec §2-3) |
| 3 | 복수교사 등록부 (`coTeaching`) | 기존 등록부 UI. 그리드 [*] 표기 과목과 대조 |
| 4-1 | 소프트 S6(오전/오후) 가중치 | "중요" = 가중치 상향, "신경 안 씀" = 0. 검사기 가중치 상수 조정은 Claude 몫(솔버·검사기 공유 상수 1곳) |
| 4-2 | 소프트 S7(순배) 구현 여부 결정 | "신경 안 씀"이면 **S7 미구현 확정**(v1 보류 중 — 실효 없는 기능 제거). "중요"면 구현 착수 판단 |
| 4-3 | 자유 응답 → 신규 소프트 규칙 후보 | Claude가 기존 S1~S6로 커버되는지 판정 후 신규 규칙 스펙화 여부 결정 |
| 5-1 | **F-2 착수 게이트** | 샘플 수령 → 인코딩(EUC-KR 여부)·컬럼 구조 실측 → F-2 CSV 직렬화 스펙 확정(phase9c_f_spec §6) → Antigravity 구현 |
| 5-2 | F-2 가상 교사(창체·SLAT) 처리 규칙 | 샘플에 창체가 안 담겨 있을 수 있어 별도 문항으로 이중 확보 |
| 5-3 | F-2 복수교사 행 직렬화 규칙 | 〃 |

- **회수 후 순서 권장**: ① 1~3번 응답을 등록부에 등재(Antigravity 또는 일과계 직접) → ② 자동 작성 실행해 하드 위반 중 "등록부미비" 잔존 확인(등재 누락 검출 — E1 진단 활용) → ③ 4번 가중치 반영(Claude) → ④ 5번 샘플로 F-2 착수(Claude 스펙).
- 질문지 본문에는 시스템 내부 용어(등록부·컴시간 매뉴얼 조항·Phase명)를 쓰지 않았다 — ui-copy-rules 정신. "컴시간" 언급은 파일 출처 지시(5-1)에만 사용(허용 범주).
